# Учёт — дашборд

Мобильный дашборд: найдено, реклама и прибыль по дням. Работает без внешних сервисов.

- Данные вносятся вручную в приложении (кнопка «Внести») и хранятся на устройстве (localStorage).
- `shared/seed.js` — разовый снимок старой Google Таблицы, загружается при первом запуске.
- Резервная копия: кнопка «Резервная копия» внизу страницы (сохранить / загрузить файл).
- `index.html` — приложение, `shared/core.js` — хранилище и расчёты.
