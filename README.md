# Учёт — дашборд

Мобильный дашборд, читает данные из Google Sheets (вкладки месяцев) и показывает итоги и дни.

- `index.html` — приложение
- `shared/core.js` — настройки таблицы (`CONFIG`), загрузка и разбор данных
- `apps-script/Code.gs` — скрипт для записи «Найдено сегодня» в таблицу (по желанию)

Новые месяцы добавляются вручную в `CONFIG.projects[].months` (gid вкладок DASH и INFO).
